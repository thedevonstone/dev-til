## Promise.allSettled vs Promise.all

`Promise.all` rejects as soon as any promise rejects — all-or-nothing.
`Promise.allSettled` waits for every promise and returns all results including failures.

```js
const results = await Promise.allSettled([fetchA(), fetchB(), fetchC()]);
results.forEach(r => {
  if (r.status === 'fulfilled') use(r.value);
  else log(r.reason);
});
```

Use `allSettled` when you want partial results.

## Optional chaining with method calls

Optional chaining `?.` works on method calls, not just property access.

```js
const len = user?.getName?.().length;
```

If `user` is null or `getName` doesn't exist, returns `undefined` instead of throwing.

## queueMicrotask for async without promises

`queueMicrotask` schedules a callback in the microtask queue — runs before the next task but after the current synchronous code.

```js
queueMicrotask(() => {
  // runs before setTimeout, after current call stack
  processQueue();
});
```

Useful when you need to defer work without the overhead of a full Promise.
