## Error.cause for chained errors

Pass `{ cause }` to Error to chain the original error without losing the stack trace.

```js
try {
  await db.query(sql);
} catch (err) {
  throw new Error('Failed to load user', { cause: err });
}
```

Access with `error.cause`. Better than appending the message string manually.

## Performance.now for precise timing

`performance.now()` returns a high-resolution timestamp in milliseconds, more precise than `Date.now()`.

```js
const start = performance.now();
doWork();
const elapsed = performance.now() - start;
console.log(`took ${elapsed.toFixed(2)}ms`);
```

Works in both Node.js and browsers. Use `performance.mark` and `performance.measure` for more structured profiling.

## Object.groupBy

`Object.groupBy` groups an array into an object by a key function. No more manual reduce.

```js
const byStatus = Object.groupBy(tasks, t => t.status);
// { todo: [...], done: [...], blocked: [...] }
```

Available in Node 21+ and modern browsers. Use `Map.groupBy` if you need non-string keys.

## queueMicrotask for async without promises

`queueMicrotask` schedules a callback in the microtask queue — runs before the next task but after the current synchronous code.

```js
queueMicrotask(() => {
  // runs before setTimeout, after current call stack
  processQueue();
});
```

Useful when you need to defer work without the overhead of a full Promise.

## Array.at() for negative indexing

`Array.at(-1)` returns the last element without needing `arr[arr.length - 1]`.
Works on strings too.

```js
const last = [1, 2, 3].at(-1);     // 3
const secondLast = 'hello'.at(-2); // 'l'
```
