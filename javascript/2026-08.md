## Array.at() for negative indexing

`Array.at(-1)` returns the last element without needing `arr[arr.length - 1]`.
Works on strings too.

```js
const last = [1, 2, 3].at(-1);     // 3
const secondLast = 'hello'.at(-2); // 'l'
```

## Temporal dead zone

`let` and `const` are hoisted but not initialized — accessing them before declaration throws a ReferenceError. This is the temporal dead zone.

```js
console.log(x); // ReferenceError
let x = 5;
```

`var` would return `undefined` instead. The TDZ is intentional — it catches a real class of bugs.
