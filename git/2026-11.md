## git rerere — reuse recorded resolution

Remembers how you resolved a merge conflict so it can apply the same fix automatically next time.

```bash
git config --global rerere.enabled true
```

Useful on long-lived feature branches that regularly rebase onto main.

## git log graph view

A compact visual of branch history directly in the terminal.

```bash
git log --oneline --graph --all --decorate
```

Worth aliasing: `git config --global alias.lg "log --oneline --graph --all --decorate"`
