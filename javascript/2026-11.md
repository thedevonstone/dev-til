## Error.cause for chained errors

Pass `{ cause }` to Error to chain the original error without losing the stack trace.

```js
try {
  await db.query(sql);
} catch (err) {
  throw new Error('Failed to load user', { cause: err });
}
```

Access with `error.cause`. Better than appending the message string manually.

## Performance.now for precise timing

`performance.now()` returns a high-resolution timestamp in milliseconds, more precise than `Date.now()`.

```js
const start = performance.now();
doWork();
const elapsed = performance.now() - start;
console.log(`took ${elapsed.toFixed(2)}ms`);
```

Works in both Node.js and browsers. Use `performance.mark` and `performance.measure` for more structured profiling.
